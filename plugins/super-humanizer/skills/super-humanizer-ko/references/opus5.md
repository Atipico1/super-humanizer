# Opus 5에서 먼저 볼 곳

공통의 반복 대조를 먼저 읽고, 아래 형태도 확인한다. 이 모델만의 문법이나 자동 삭제 목록이 아니다. **전은 실제 초안 발췌, 후는 편집 제안**이다. 새 윤문 실행으로 검증된 결과는 아니다.

## 1. 같은 판단을 문장 조각으로 거듭 강조하기

**눈여겨볼 형태:** '~하는 사람.', '~하는 물건.'처럼 같은 명사로 끝나는 조각이 이어지거나, 설명 뒤에 짧은 판단 문단을 다시 세운다.
**문제와 수정:** 짧은 문장이 앞의 판단을 바꿔 말하기만 하면 여운보다 지연이 생긴다. 새 정보를 담은 조각은 살리고 같은 판단을 되풀이하는 조각만 덜어낸다.

전: “도착한 뒤에도 도착을 기다리는 사람. 이미 와 있는데도 아직 오지 않았다고 느끼는 사람.”
후: “도착한 뒤에도 도착을 기다리는 사람.”

**유지:** 같은 초안의 “어쩌면 지금도.”는 과거 기차 장면의 감각을 현재로 옮긴다. 다른 초안의 “김솔통 같은 글을 쓰고 싶다.”도 필자가 찾은 목표를 처음 제시한다. 짧다는 이유로 합치지 않는다.

## 2. 소제목과 본문 사이에 같은 예고 넣기

**눈여겨볼 형태:** 소제목 아래의 '문제는 ~이다', '한 가지 깨달은 게 있다', '이야기해보려 한다'가 실제 설명을 한 문단 늦춘다. 블로그에서 우선 점검한다.
**문제와 수정:** 소제목이 이미 말한 내용을 다시 예고할 뿐이면 실제 설명으로 바로 잇는다. 도입에 있던 시점·대상·화자의 태도는 잃지 않는다.

전: 소제목 “겨울은 조금 힘들다” → “문제는 겨울이다.” → “해가 짧아지면 내 작업 시간도 같이 짧아진다.”
후: 소제목을 두고 바로 “해가 짧아지면 내 작업 시간도 같이 짧아진다.”로 잇는다.

다른 관찰: 소제목 “일상이 있어야 여행이 빛난다” 아래의 “또 하나 깨달은 게 있다.”를 덜고, 다음 문장 “여행이 특별한 이유는 그게 일상이 아니기 때문이다.”로 시작할 수 있다.

**유지:** “그로부터 5년이 지났다.”처럼 실제 시간을 옮기는 문장, 새 인물이나 문제를 처음 꺼내는 도입은 기능이 있다. 사건 예고가 있다는 것만으로 삭제하지 않는다.

## 3. 핵심 구별을 다른 대조로 계속 변주하기

**눈여겨볼 형태:** 본문에서 설명한 'A가 아니라 B'가 소제목·중간 총평·결말에도 다시 놓인다. 부정과 긍정이 두 문장으로 갈라진 경우도 같다.
**수정 방향:** 공통 대조 예시처럼 같은 구별의 재진술을 줄인다. 단어만 다른 대조로 교체하거나 모든 부정을 긍정문으로 바꾸지 않는다.

**유지할 실제 예:** “그저 고민의 단위가 커질 뿐.”은 시간과 돈이 늘어도 여행 계획의 고민이 사라지지 않을 것이라는 바로 앞 가정을 마무리한다. 짧은 결론이면서 부연이라는 이유만으로 지울 필요는 없다.

## 4. 삽입 설명을 엠대시로 계속 연결하기

**눈여겨볼 형태:** 서로 다른 역할의 삽입·해설·정정을 모두 같은 대시로 연결해 호흡이 반복된다.
**수정 방향:** 설명이 수식하는 명사 곁으로 옮기거나 문장에 직접 연결한다. 괄호나 쉼표로 일괄 치환하지 않는다.

전 → 후 **(설명용 구성 예시):** “그 카페는 — 내가 낮마다 글을 쓰는 곳인데 — 겨울에는 일찍 어두워진다.” → “내가 낮마다 글을 쓰는 그 카페는 겨울에는 일찍 어두워진다.”

**유지:** 인용에 든 대시, 저자의 문체 샘플에서 쓰는 삽입, 의미 있는 급전환은 부호만 보고 없애지 않는다.

# 보존과 문체를 구별하기

## 내용·태도 보존 G

통과 / 실패 / 보류. 초안의 사실·수치·이름·인용·주장·인과·부정·조건·가능성·의무·확신·화자 입장을 후보와 대조한다. 실질적인 추가·누락·변경은 실패다. 중복 표현을 합쳐 같은 명제를 남긴 것은 누락이 아니다. 초안 자체의 사실성은 별도 문제이며 잘못을 임의로 고친 후보도 보존 변경을 기록한다.

근거는 원문 구절 → 후보 구절과 변화의 의미를 쓴다. 누락은 '대응 구절 없음', 추가는 '원문 근거 없음'. 불확실한 대응을 억지로 실패나 통과로 만들지 않는다.

## 품질 F / D / S

각각 0(뚜렷한 문제), 1(국소 문제), 2(뚜렷한 문제 없음), 미확인. 2는 사람 작성 판정이 아니다.

- F 유창성: 호응·수식 범위·어휘 결합·읽기 흐름. 오탈자를 인간다움으로 보상하지 않는다.
- D 담화: 연결·지시 대상·예시 역할·정보 없는 반복. 짧거나 길다는 이유만으로 가감하지 않는다.
- S 문체: 장르·독자·격식·화자에 맞는 표현과 리듬. 내용과 무관하게 같은 재정의 틀로 여러 문단을 닫거나, 평범한 주장마다 격언처럼 강조하거나, 매번 동일한 위로·교훈으로 마감하는지 살핀다. 실제 해당 문구와 위치를 인용하고 반복이 어떤 어조를 만드는지 설명한다. 이 예시를 필수 결함 목록으로 쓰지 않는다.

사람 참조의 실제 표현·구조와 대조한다. 한 사람을 정답 문체로 삼지 않는다. 다른 참조에 같은 기법이 유효하게 쓰이면 반례로 고려한다. 3개 발췌는 모집단 분포가 아니다. 없는 빈도·백분위·통계를 만들지 않는다. 엠대시, 곡선 따옴표, 존댓말, 접속사, 목록의 존재만으로 감점하지 않는다. 특정 표현이 반복되어 실제 문맥과 어긋나는 양상을 평가한다.

## 선호 판정

보존 통과 후보만 채택 가능하다. 둘 다 통과하면 한 축에서 인용으로 뒷받침되는 개선이 있고 다른 축이 실질적으로 악화되지 않을 때만 우세다. 개선과 악화가 엇갈리면 동률. 근거 불충분은 보류. 수정량·길이·화려함·패턴 삭제 건수에 가산점 없음. 원문을 유지하는 것이 더 나을 수 있다.

최소 출력: 후보별 G/F/D/S, 국소 근거, A/B/동률/보류, 초안 대비 개선/동일/악화. 보존 위반은 모두 남긴다. 서로의 평가를 보지 않은 평가자 결과를 보존하고 순서 민감·평가자 불일치를 숨기지 않는다. 자동 판정은 사람이 검증한 정답이 아니다.
